
### Important Follow-up

RightMenu 0.1.44 is a small but important follow-up released shortly after
0.1.43. It makes the new official plugin system easier to discover by adding a
prominent Download Plugins link directly beside Import Signed Plugin in
Settings.

### What's New

- Added a highlighted Download Plugins link to **Settings > Plugins**.
- The link opens the official plugin download section in the public RightMenu
  repository.
- Refresh and Desktop Items can be downloaded and updated independently as
  official signed plugins.

### Highlights from 0.1.43

If you missed the previous release, RightMenu recently received a major update:

- Introduced the independently versioned, signed plugin platform.
- Added secure plugin importing, publisher verification, access review, updates,
  and isolated execution.
- Moved Refresh and Desktop Items into separately downloadable official plugins.
- Added Developer ID signing, Apple notarization, stapling, and Gatekeeper
  verification for public releases.
- Kept New File, Copy File Path, and file information built into RightMenu and
  independent from optional plugins.

### Upgrade Note

Users upgrading from an earlier version should open **Settings > Plugins** and
select **Download Plugins** to install Refresh or Desktop Items if they want
those optional Finder actions.
